There are lots of new concepts.. but it's mostly all I've been doing when it comes to code. I am also so tired of trying to fight with my workflows on a Mac. Currently, I have decent window management due to a custom hammerspoon implementation that essentially gives me tags.. It works by storing focused applications into "groups", and then swapping through groups with Command+number, as well as Command+Tab to flip through applications in a group. Without workspaces, there are no animations. It's all fake, simply bringing the application to the foreground in full-screen.. This is okay for window management, but there is still much to be desired, especially when it comes to my terminal. I learned the most about linux with hyprland, because at the start, I didn't understand anything, and it doesn't do anything for you.. It's pretty exciting, because dwl is extremely barebones and offers basically nothing for you, it requires patches or modifying the source code to add any additional functionality. I'm umbracing suckless principles, and starting to really dig into software that I have to modify and compile myself. In this way, I can sort of embrace minimalism, and have a much quicker, more responsive desktop environment.. I'm really excited to see where this goes, moving forward, because I don't see myself going away from this workflow anytime soon, it feels so clean compared to plasma or even hyprland!
